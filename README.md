# نظام إدارة مكتب المحاماة - النسخة السورية ⚖️
### Syrian Law Office Management System (Damascus Courts Edition)

تطبيق متكامل لإدارة مكاتب المحاماة في الجمهورية العربية السورية، مصمم ليعمل **بشكل محلي بالكامل (Offline-First)** دون الحاجة للاتصال بالإنترنت، مع توافق كامل ومباشر مع إجراءات التقاضي ومحاكم دمشق والمحافظات السورية.

---

## 📋 نظرة عامة على المشروع (Project Overview)

تم بناء التطبيق باستخدام إطار العمل **Flutter** مع بنية برمجية قائمة على هندسة الطبقات (**Layered Architecture**) ونمط إدارة الحالة المتقدم **Riverpod** مع قاعدة بيانات علائقية محلية فائقة السرعة **Drift (SQLite)**.

النظام يلبي كافة متطلبات المحامي السوري اليومية:
1. قيد وإدارة القضايا والدعاوى المدنية والجزائية والشرعية والتجارية والعمالية.
2. دعم **الموكلين المتعددين** و**الخصوم المتعددين** في نفس ملف الدعوى.
3. إدارة **جلسات المحاكمة** مع نظام تاريخي دقيق لتأجيل الجلسات وتوثيق أسباب التأجيل والقرارات.
4. تقويم قضائي تفاعلي (شهري / أسبوعي) مع إشعارات وجدول أعمال يومي.
5. إدارة الشؤون المالية والأتعاب والدفعات والمصاريف القضائية بالليرة السورية ومختلف العملات.
6. أرشيف للمستندات والملفات المرفقة بصيغ متعددة مع إمكانية إعادة التسمية.
7. تسجيل صوتي للملاحظات القضائية والإجراءات عبر الإملاء الصوتي (Speech-to-Text).
8. أمان وحماية عالية عبر البصمة الحيوية (Biometrics) ورمز المرور الشخصي (PIN).
9. مركز نسخ احتياطي واستعادة محلي مشفر ومضغوط بصيغة ZIP.
10. مكتبة قانونية لنماذج وصيغ الدعاوى القضائية السورية.

## ✨ أهم الميزات والتعديلات المنجزة (Key Features & Implementations)

### 1. دعم الموكلين المتعددين والخصوم المتعددين (Multiple Clients & Opponents)
- **موكلون متعددون في القضية الواحدة**:
  - إمكانية إضافة أكثر من موكل عبر زر `+ إضافة موكل`.
  - تحديد صفة كل موكل بشكل مستقل (`مدعي` باللون الأزرق أو `مدعى عليه` باللون الأحمر).
  - قائمة ديناميكية لأرقام الهواتف لكل موكل مع تحديد نوع الرقم (محمول / واتساب / هاتف أرضي) مع زر الحذف والإضافة (+).
  - حقول الرقم الوطني، عنوان الإقامة، وعنوان المختار لكل موكل بشكل مدمج ومنظم.
  - إمكانية حذف أي موكل إضافي بضغطة زر.
- **خصوم متعددون في القضية الواحدة**:
  - إمكانية إضافة أكثر من خصم عبر زر `+ إضافة خصم`.
  - تحديد صفة كل خصم بشكل مستقل (`مدعى عليه` أو `مدعي`).
  - أرقام هواتف متعددة، رقم وطني، عنوان إقامة، وعنوان مختار لكل خصم.
  - إمكانية حذف أي خصم إضافي بسهولة.
- **عرض الأطراف في تفاصيل القضية**:
  - عرض بطاقات كافة الموكلين مع أرقام هواتفهم وصفاتهم والولوج السريع لملف الموكل.
  - عرض بطاقات كافة الخصوم مع إمكانية تعديل بيانات كل خصم بشكل منفصل.

### 2. إدارة جلسات المحاكمة المتسلسلة (Hearings & Postponements Tracking)
- **الترتيب الهرمي المتقدم للجلسات**:
  1. الجلسات القادمة (مجدولة في المستقبل).
  2. الجلسات التي أجلت وكان موعد التأجيل في المستقبل.
  3. الجلسات التي تمت وحسمت.
  4. الجلسات المؤجلة وتمت في الماضي.
- **سجل التأجيلات التاريخي (Postponement History)**:
  - دعم تأجيل الجلسة لعدة مرات متتالية دون فقدان البيانات.
  - إمكانية النقر على `عرض سجل هذه الجلسة` لمعرفة عدد مرات التأجيل وتاريخ وسبب كل تأجيل.
  - إنشاء سجلات جلسات جديدة تلقائياً عند التأجيل لتبقى كافة الجلسات واضحة في الجدول.
  - ضبط أزرار التحكم المتجاورة (`تأجيل الجلسة` و`تسجيل القرار`) بتنسيق متوازن ومتناسق.

### 3. التقويم القضائي التفاعلي وجدول الأعمال (Interactive Judicial Calendar)
- **عرض أسبوعي وشهري**:
  - زر تبديل سلس بين العرض الشهري والعرض الأسبوعي في رأس التقويم.
  - عرض أسبوعي رحب وواضح يظهر اليوم والتاريخ واسم اليوم.
  - تمييز اليوم الذي يحتوي على جلسات أو مهام بلون دلالي بارز وشارة `موعد`.
- **جدول أعمال اليوم المحدد**:
  - عرض اسم الموكل ونوع القضية وموضوع الجلسة/المهمة.
  - النقر على العنصر يفتح ملف الموكل أو ملف القضية مباشرة.
  - إمكانية إضافة سريعة لمهمة أو جلسة لأي يوم من التقويم مباشرة.
- **القضايا الحالية قيد النظر**:
  - عرض أول 5 قضايا نشطة مع زر للانتقال المباشر لقسم القضايا في القائمة السفلية.

### 4. إصلاحات الاستقرار ومنع الانهيارات (Stability & Bug Fixes)
- **إصلاح خطأ SQLite Error 787 (Foreign Key Constraint Violation)**:
  - تم تشخيص وحل خطأ انهيار قاعدة البيانات عند إعادة فتح التطبيق الناتج عن استدعاء حذف المحاكم في مرحلة `beforeOpen`.
  - الحفاظ على بيانات القضايا والمحاكم كاملة دون مساس.
- **معالج الأخطاء المرئية الشامل (Global ErrorWidget Handler)**:
  - استبدال الشاشة الحمراء الافتراضية في Flutter ببطاقة تنبيه أنيقة تمنع توقف التطبيق أو إزعاج المستخدم.
- **التوافق مع مختلف أحجام الشاشات وتكبير الخطوط (Multi-Screen & Accessibility)**:
  - دعم التمرير التلقائي وحل كافة مشاكل تجاوز الحواف (`RenderFlex overflow`) عند استخدام أحجام خطوط كبيرة جداً أو شاشات مختلفة الأبعاد (1080x2400 وغيرها).
  - استخدام `FittedBox` و`Flexible` للنصوص الطويلة لضمان بقائها على سطر واحد أو التواءها بانسيابية.
- **الملاحظات الصوتية (Speech-to-Text)**:
  - تفعيل الإملاء الصوتي في كافة حقول الملاحظات وإجراءات الجلسات والمهام.

## 🏗️ البنية التقنية (Tech Stack & Architecture)

| المجال | التقنية المستخدمة | الوصف |
| :--- | :--- | :--- |
| **Framework** | [Flutter](https://flutter.dev) (Dart 3.x) | إطار عمل متعدد المنصات عالي الأداء |
| **State Management** | [Riverpod 2.x](https://riverpod.dev) | إدارة الحالة التفاعلية وحقن الاعتماديات |
| **Local Database** | [Drift](https://drift.simonbinder.eu) (SQLite) | قاعدة بيانات محلية آمنة عالية السرعة مشفرة المفاتيح |
| **Navigation** | [GoRouter](https://pub.dev/packages/go_router) | توجيه وإدارة الصفحات مع شريط ملاحة سفلي مفهرس |
| **Security & Auth** | `local_auth` & `flutter_secure_storage` | حماية بالبصمة الحيوية وPIN وتخزين آمن في Android Keystore |
| **Speech-to-Text** | `speech_to_text` | التعرف الصوتي على الكلام وتحويله لنصوص عربية فورية |
| **Backup Engine** | `archive` (ZIP) & `path_provider` | ضغط واستخراج النسخ الاحتياطية محلياً مع فحص سلامة SHA-256 |
| **UI Design** | Material 3 + RTL Arabic | دعم كامل للغة العربية والمظهر الفاتح والداكن وثيمات ألوان متعددة |

│   ├── contacts/          # دليل المحامين والخبراء والجهات القضائية

│   ├── file_manager/      # مستودع المستندات والملفات المرفقة

│   ├── hearings/          # جلسات المحاكمة، التأجيلات، وسجل القرارات
│   ├── legal_ai/          # المساعد القانوني الذكي (Google Gemini)
│   ├── legal_library/     # صيغ الدعاوى والإنذارات العدلية السورية
│   ├── security/          # شاشة قفل التطبيق وإدخال الـ PIN
│   ├── settings/          # إعدادات المظهر، الأمان، والخطوط
│   └── tasks/             # المهام والمهل القانونية
└── shared/
    └── widgets/           # العناصر المشتركة (بطاقات، حقول نصوص، شارات حالة)

## 🚀 كيفية تشغيل وبناء التطبيق (Run & Build)

### المتطلبات الأساسية (Prerequisites):
- تثبيت Flutter SDK (الإصدار 3.24 أو أحدث).
- Android SDK مع تفعيل USB Debugging على الهاتف.

### 1. تثبيت الحزم والمكتبات:
```bash
flutter pub get
```

### 2. توليد أكواد قاعدة البيانات (Drift Code Generation):
```bash
dart run build_runner build --delete-conflicting-outputs
```

### 3. فحص سلامة الكود (Linting & Analysis):
```bash
dart analyze lib
```

### 4. تشغيل التطبيق على الهاتف المتصل:
```bash
flutter run -d <DEVICE_ID>
```
*مثال للتشغيل على جهاز محدد:*
```bash
flutter run -d 7TK7EEWGAQLZXS6L
```

### 5. بناء ملف APK للتثبيت:
```bash
flutter build apk --release
```

## 🛡️ الأمان والخصوصية (Security & Privacy)
- التطبيق لا يشارك أي بيانات على أي خوادم خارجية؛ كافة السجلات والوثائق تُحفظ على ذاكرة الهاتف الداخلية حصراً.
- النسخ الاحتياطية تُنشأ محلياً بصيغة ملف مضغوط يمكن للمحامي نقله وتخزينه على قرص خارجي أو وسيط آمن.
- مفاتيح الـ API المشفرة تُخزن في مخزن المفاتيح الآمن للنظام (**Android Keystore**).
